# NGG Quiz - פלטפורמת חידונים אינטראקטיביים

פלטפורמה פנים-ארגונית ליצירה והפעלה של חידונים אינטראקטיביים בזמן אמת, בסגנון Kahoot:
מנהלים יוצרים חידונים בספרייה משותפת, מפעילים אותם מול קהל, והמשתתפים עונים מהטלפון
וצוברים ניקוד לפי נכונות התשובה ומהירות המענה.

- **צד לקוח:** React + Vite, אתר סטטי המתאים ל-GitHub Pages (ניווט מבוסס Hash).
- **צד שרת:** Supabase - אימות מנהלים, מסד נתונים (PostgreSQL), אחסון לוגואים (Storage) ו-Realtime לעדכונים חיים.
- **ניקוד:** מחושב בצד השרת (Trigger) - תשובה נכונה מזכה ב-500 עד 1000 נקודות בדעיכה מעריכית לפי מהירות המענה (מענה מיידי ≈ 1000, אחרי כ-30 שניות ≈ 684, מענה איטי מאוד מתכנס ל-500). כך לא ניתן לזייף ניקוד מהדפדפן.

## יכולות

- התחברות מנהלים (דוא"ל + סיסמה דרך Supabase Auth).
- יצירת חידון: כותרת, תת-כותרת, לוגו לקוח למסך הפתיחה, שאלות עם 2-4 מסיחים, סימון תשובה נכונה וסידור סדר השאלות.
- ספריית חידונים משותפת לכלל המנהלים; עריכה זמינה ליוצר החידון בלבד.
- הפעלת חידון מפיקה שני קישורים: **מסך מוקרן** (לוח המנחה) ו**קישור הצטרפות למשתתפים** (כולל קוד PIN וקוד QR).
- מהלך משחק חי בשליטת המנחה: אין מגבלת זמן למענה - המנחה חושף את התשובה ומתקדם לשאלה הבאה בלחיצת כפתור מהמסך המוקרן. כולל לובי מצטרפים, התפלגות תשובות, טבלת מובילים ופודיום סיום עם אנימציות וקונפטי - הכול מסתנכרן בזמן אמת בין כל המסכים.

## הקמה חד-פעמית

### 1. הקמת פרויקט Supabase

1. צרו פרויקט חדש ב-[supabase.com](https://supabase.com).
2. פתחו את **SQL Editor** והריצו את תוכן הקובץ [`supabase/schema.sql`](supabase/schema.sql) - הוא יוצר את הטבלאות, חוקי האבטחה (RLS), חישוב הניקוד, אחסון הלוגואים וה-Realtime.
   (אם הרצתם בעבר גרסה קודמת של הסכמה, הריצו במקום זאת את קובץ המיגרציה שב-`supabase/migrations/`.)
3. תחת **Authentication → Sign In / Up** מומלץ לכבות הרשמה עצמית (Disable new user signups), ולהוסיף את המנהלים ידנית דרך **Authentication → Users → Add user** (דוא"ל + סיסמה).
4. מתוך **Project Settings → API** העתיקו את `Project URL` ואת `anon public key`.

### 2. הרצה מקומית

```bash
cp .env.example .env    # ומלאו את שני הערכים מ-Supabase
npm install
npm run dev
```

### 3. דפלוי ל-GitHub Pages

1. בהגדרות הריפוזיטורי: **Settings → Secrets and variables → Actions** הוסיפו שני Secrets:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
2. תחת **Settings → Pages** בחרו Source: **GitHub Actions**.
3. כל דחיפה ל-`main` מפעילה את ה-Workflow שבקובץ `.github/workflows/deploy.yml` ובונה ומפרסם את האתר אוטומטית.

> הערה: מפתח ה-anon של Supabase מיועד מטבעו לצד הלקוח והוא חשוף בדפדפן; ההרשאות בפועל נאכפות על ידי חוקי ה-RLS שבסכמה.

## תפעול שוטף

1. **יצירה:** התחברו, לחצו "חידון חדש", מלאו כותרת ותת-כותרת, העלו לוגו לקוח (רשות), הוסיפו שאלות ומסיחים, סמנו את התשובה הנכונה, סדרו את השאלות בחצים ושמרו.
2. **הפעלה:** בספרייה לחצו "הפעלה". יוצג מסך עם קוד ההצטרפות ושני הקישורים - העתיקו את קישור המסך המוקרן למחשב ההקרנה (בדפדפן מחובר לחשבון האדמין) ושתפו את קישור המשתתפים.
3. **ניהול המשחק:** כולו בידי המנחה מהמסך המוקרן - התחלת החידון, חשיפת התשובה בלחיצת כפתור (מוצג מונה של מי שכבר ענה וזמן שחלף), מעבר לשאלה הבאה או לטבלת המובילים, וסיום בפודיום. אין מגבלת זמן למענה, אך מענה מהיר מזכה בניקוד גבוה יותר.

## הערות אבטחה ותחומי אחריות

- כתיבה (יצירת חידונים, שליטה במשחק) מוגבלת למשתמשים מחוברים; שליטה במפגש שמורה למנהל שפתח אותו בלבד.
- משתתפים אינם נדרשים לחשבון - הם מצטרפים עם קוד PIN בלבד ויכולים רק להירשם למשחק ולשלוח תשובות בזמן שאלה פתוחה.
- הניקוד ושעת תחילת השאלה נקבעים לפי שעון מסד הנתונים, ולא לפי שעון המחשב של המשתתף או המנחה.
- המערכת מיועדת לשימוש פנים-ארגוני. תוכן החידונים נגיש לכל מי שמחזיק בקישור לפרויקט, לכן אין להזין בה מידע רגיש או סודי.
